# HEDS Operating Discipline Academy
## GitHub Pages Repository

This repo hosts the HEDS Academy training platform — a single GitHub Pages site with:
- `index.html` — Academy landing page with overview and links to each program
- `service-manager-dashboard.html` — Service Manager Training (20 modules, 50-question assessment)
- `rental-service-manager-dashboard.html` — Rental Service Manager Training (7 modules)
- `rental-manager-dashboard.html` — Rental Manager Training (8 modules)
- `parts-manager-dashboard.html` — Parts Manager Training (6 modules)
- `LOGO_HEDS.png` / `LOGO_HEDS_small.png` — brand assets

All dashboards are standalone single-file HTML with inline CSS and JS. No build step required.

Live URL: https://drlooper-bit.github.io/heds-academy/
