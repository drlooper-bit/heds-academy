How It Works

1

Pre-Work (Remote, 3–5 Days Before)

Lightweight data package — four out-of-the-box reports, no raw ERP dumps required. HEDS returns a one-page Current State Scorecard before onsite start.

2

Onsite Intensive (2–4 Days)

Classroom + floor time + live process redesign using the client's real data. Every participant builds their own scorecard and 90-day action plan. Cap: 8–12 leaders per cohort.

3

Follow-Up Coaching (Optional, Performance-Triggered)

Virtual sessions focused on the specific areas where execution is not progressing as planned. Purchased separately or as a bundled coaching package after the onsite. Not automatic — engaged only where the client wants continued accountability.

Curriculum Design

Every program begins with a shared financial foundation so all participants — service, parts, rental, branch — speak the same language:

  • Absorption rate and what it means for the dealership
  • EBITDA and margin drivers
  • ROI on operational decisions
  • Variable vs. fixed expense management

After the foundation, participants break into position-specific tracks with standards, checklists, scorecards, and role-play exercises tailored to their daily responsibilities.

Every module follows the same structure: Diagnose → Standard → Rhythm → KPI → Role-Play → Accountability. If the participant cannot leave the room and execute the standard tomorrow without HEDS present, the module is filler.
